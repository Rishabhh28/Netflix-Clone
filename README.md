# Netflix Landing Page Clone

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![Static Site](https://img.shields.io/badge/Static%20Site-No%20Framework-black?style=for-the-badge)

A handcrafted Netflix India landing page clone built with pure HTML and CSS. The project recreates the bold, cinematic first impression of Netflix with a dark hero section, branded visual treatment, trending content cards, feature highlights, FAQ layout, and footer navigation.

## Preview

Open `index.html` in your browser to view the page locally.

## Highlights

- Fully handcrafted layout using only HTML and CSS
- Netflix-style hero section with background image and dark overlay
- Language selector and sign-in button in the navigation bar
- Email capture call-to-action sections
- Horizontal "Trending Now" poster row with numbered cards
- Smooth hover scaling on movie/show posters
- Feature cards for membership benefits
- FAQ-style question rows with plus icons
- Footer link columns inspired by the original Netflix landing page
- Custom Netflix-style font loaded locally

## Tech Stack

- HTML5
- CSS3
- Local assets
- Custom font file
- No JavaScript framework
- No build tools required

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Launch `index.html` in any modern browser.

That is it. Since this is a static project, there is no dependency installation, no server setup, and no build command.

## What I Practiced

This clone focuses on core frontend fundamentals:

- Building page sections from scratch
- Using flexbox for layout
- Creating overlays and layered hero designs
- Styling forms, buttons, cards, and navigation
- Managing local assets and external poster images
- Recreating a professional streaming-platform landing page aesthetic
